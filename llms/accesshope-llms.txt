# AccessHope

> AccessHope is a health benefits company, founded in 2019 and wholly owned by City of Hope, that delivers remote cancer expertise as an employer-sponsored benefit. Subspecialist teams at a coalition of NCI-designated Comprehensive Cancer Centers review a member's case and return guidance to the member's own local oncologist. Roughly 9 million covered members across 700+ employer and health-plan clients.

This file is an API Evangelist-generated catalog summary. AccessHope does not publish an
llms.txt of its own (https://www.myaccesshope.org/llms.txt returned 404 on 2026-08-06).

## API surface

AccessHope publishes **no public API**: no developer portal, no API reference, no OpenAPI /
AsyncAPI / GraphQL / Postman artifact, no SDK on npm, PyPI, RubyGems, Packagist or NuGet, and
no `/.well-known/` discovery documents. Client onboarding is a weekly eligibility file feed
coordinated by an implementation team, not a self-service API.

Authenticated web applications exist but are end-user products, not developer surfaces:

- app.myaccesshope.org — member/staff portal (Next.js + NextAuth, credentials provider only; `robots.txt` = `Disallow: /`)
- docs.myaccesshope.org — document portal behind login (not developer documentation)
